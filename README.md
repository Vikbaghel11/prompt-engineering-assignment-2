# Prompt Engineering Assignment 2

## Project Overview
This project contains three Python programs developed with
AI assistance as part of a Prompt Engineering assignment.

## Objectives
- Calculate the factorial of a number.
- Generate the Fibonacci series.
- Represent a C structure using a Python dictionary.
- Understand the differences between C and Python.
- Explore AI-assisted documentation and GitHub version control.

## Technologies Used
- Python
- Google Colab
- GitHub
- AI coding assistance

## Programs

### 1. Factorial
Calculates the factorial of a non-negative integer.

### 2. Fibonacci Series
Generates the first n terms of the Fibonacci sequence.

### 3. C Structure to Python Dictionary
Demonstrates how student information represented by a C structure
can be stored in an equivalent Python dictionary.

## Project Structure

- factorial.py
- fibonacci.py
- c_structure_to_dictionary.py
- README.md

## How to Run

Run each program using Python:

    python factorial.py
    python fibonacci.py
    python c_structure_to_dictionary.py

## Conclusion
This project demonstrates basic Python programming, AI-assisted
code generation, documentation, and GitHub version control.
